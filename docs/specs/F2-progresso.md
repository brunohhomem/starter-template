## Decisões tomadas

| Data       | Decisão                                                                                                                                            | Motivo                                                                                                                                                               |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-10-22 | Repositories recebem transaction opcional                                                                                                          | Service não deve importar drizzle-orm; operações compostas (rotação) usam transação via repository                                                                   |
| 2026-10-22 | DatabaseTransaction tipado como NodePgTransaction<any, any>                                                                                        | Tipos complexos do drizzle-orm não compatíveis com schema estendido; funcionalidade preservada                                                                       |
| 2026-10-22 | Guards registrados como APP_GUARD em ordem: Origin → JwtAuth → Roles → MustChangePassword                                                          | Throttler (T8) será inserido antes do Origin; ordem segue especificação                                                                                              |
| 2026-10-22 | MustChangePasswordGuard permite GET /auth/me, POST /auth/change-password, POST /auth/logout                                                        | Regra da seção 4 da spec                                                                                                                                             |
| 2026-10-22 | OriginGuard permite requisições sem header Origin                                                                                                  | curl, testes, server-to-server                                                                                                                                       |
| 2026-10-22 | Throttler com storage Redis próprio (FailOpenRedisThrottlerStorage)                                                                                | @nest-lab/throttler-storage-redis compatível mas falha aberta não suportada; implementação própria com Lua script atômico (INCR + PEXPIRE) e fail-open em erro Redis |
| 2026-10-22 | 5 throttlers nomeados: default (120/60s), login (5/15m+block 15m), register (5/60m+block 60m), refresh (30/60s), change-password (5/15m+block 15m) | Conforme spec T8; TTL e blockDuration em ms                                                                                                                          |
| 2026-10-22 | Ordem de guards: Throttler → Origin → JwtAuth → Roles → MustChangePassword                                                                         | Spec exige throttler antes de Origin; AppThrottlerGuard estende ThrottlerGuard com generateKey por throttler                                                         |
| 2026-10-22 | Health endpoint isento de todos throttlers via @SkipThrottle                                                                                       | Spec exige /health sem rate limit                                                                                                                                    |
| 2026-10-22 | Seed admin idempotente com transação                                                                                                               | Nunca sobrescreve senha; dev usa Admin@12345 fixa; prod gera 24 chars aleatórios impressos uma vez; registration_enabled criado apenas se não existir                |
