## Tarefa T4 — Repositories

### Padrão do projeto

**Padrão de Repository** (baseado em `apps/api/src/modules/auth/sessions.repository.ts`):
```typescript
import { eq, and, lt } from 'drizzle-orm';
import { Inject, Injectable } from '@nestjs/common';
import type { Database, DatabaseTransaction } from '../../database/database.module';
import { DATABASE } from '../../database/database.module';
import { minhaTabela, type MinhaEntity, type NovaMinhaEntity } from './minha.entity';

@Injectable()
export class MinhaRepository {
  constructor(@Inject(DATABASE) private readonly db: Database) {}

  async findById(id: string, tx?: DatabaseTransaction): Promise<MinhaEntity | null> {
    const client = tx ?? this.db;
    const result = await client.select().from(minhaTabela).where(eq(minhaTabela.id, id)).limit(1);
    return result[0] ?? null;
  }
}
```

### O que implementar

#### 1. Criar `apps/api/src/modules/email-tokens/email-tokens.repository.ts`

Métodos obrigatórios:

**`create(userId, type, tokenHash, expiresAt, tx?)`** → `EmailToken`
```typescript
async create(
  userId: string,
  type: 'email_confirmation' | 'password_reset' | 'invite',
  tokenHash: string,
  expiresAt: Date,
  tx?: DatabaseTransaction,
): Promise<EmailToken>
```
Insere com `.returning()`. Se não retornar resultado, lança `new Error('Failed to create email token')`.

**`consume(tokenHash, type, tx?)`** → `EmailToken | null`
```typescript
async consume(
  tokenHash: string,
  type: 'email_confirmation' | 'password_reset' | 'invite',
  tx?: DatabaseTransaction,
): Promise<EmailToken | null>
```
Atomicidade obrigatória: um único `UPDATE ... WHERE used_at IS NULL AND expires_at > now() RETURNING`.
Use Drizzle:
```typescript
const now = new Date();
const result = await client
  .update(emailTokens)
  .set({ usedAt: now, updatedAt: now })
  .where(
    and(
      eq(emailTokens.tokenHash, tokenHash),
      eq(emailTokens.type, type),
      isNull(emailTokens.usedAt),
      gt(emailTokens.expiresAt, now),
    ),
  )
  .returning();
return result[0] ?? null;
```
Imports necessários: `eq, and, isNull, gt, lt` de `drizzle-orm`.

**`invalidateByUserAndType(userId, type, tx?)`** → `void`
```typescript
async invalidateByUserAndType(
  userId: string,
  type: 'email_confirmation' | 'password_reset' | 'invite',
  tx?: DatabaseTransaction,
): Promise<void>
```
Marca `used_at = now()` para todos os tokens do usuário com o tipo dado que ainda não foram usados (`used_at IS NULL`).

**`deleteExpiredBefore(date, tx?)`** → `number`
```typescript
async deleteExpiredBefore(date: Date, tx?: DatabaseTransaction): Promise<number>
```
Deleta tokens cujo `expires_at < date`. Retorna `result.rowCount ?? 0`.

Imports: `eq, desc, count, and` de `drizzle-orm`; `sql` de `drizzle-orm` se necessário.
